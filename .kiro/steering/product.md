# MaxQ Product Overview

MaxQ is an iOS application built with SwiftUI that appears to be in early development stages. Currently, it implements a basic Core Data-backed list interface with the ability to add and delete timestamped items.

## Current Features
- Simple list-based interface
- Core Data persistence with timestamp tracking
- Add/delete functionality for items
- Navigation-based UI structure

## Architecture
- SwiftUI-based iOS app
- Core Data for local persistence
- MVVM pattern with SwiftUI's declarative approach
- Environment-based dependency injection for Core Data context
